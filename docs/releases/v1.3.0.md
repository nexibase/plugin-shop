# v1.3.0 — Official administrator badges

Product reviews and Q&A display the same verified administrator shield as the community platform. The badge is determined by the core server's administrator identities, never by nickname text.

Requires NexiBase v0.31.0 or later for `VerifiedAdminBadge` and the corresponding identity endpoint. No database schema or payment behavior changes.

상품 리뷰와 질문의 작성자 이름 옆에 공식 관리자 방패 배지를 표시합니다. NexiBase v0.31.0 이상이 필요하며 DB 스키마와 결제 흐름의 변경은 없습니다.
