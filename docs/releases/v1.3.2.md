# v1.3.2 — 삭제된 상품이 있는 주문의 타입 수정

상품이 삭제된 뒤에도 보존되는 주문 상품의 타입을 현재 DB 구조와 맞췄습니다.

- 재고 복구 함수가 nullable `productId`를 받도록 수정했습니다. 기존 null 검사를 유지해 삭제된 상품의 재고는 갱신하지 않습니다.
- 주문 취소·환불·삭제 경로의 TypeScript 오류를 해결했습니다. 결제 처리와 재고 복구의 실행 동작은 변경하지 않습니다.
- 추가 DB 마이그레이션이나 데이터 초기화가 필요하지 않습니다.

NexiBase v0.33.1과 함께 전체 TypeScript 검사, 자동 테스트 81개와 프로덕션 빌드를 확인했습니다.
